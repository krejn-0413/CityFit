# CityFit 城宜 — 评分逻辑详解（按 32 座城市整理）

> 数据来源：`src/data/questions.ts`（18 道题目分值）、`src/composables/useMatching.ts`（匹配算法）

---

## 一、评分算法总览

最终匹配度由以下步骤计算（见 `src/composables/useMatching.ts` 的 `calculateResults()`）：

### 步骤 1：基础评分累加
遍历用户 18 道题的所有答案，累加每个城市在各题选项中的原始分值。

### 步骤 2：归一化
将最高分城市映射为 100 分，其余城市按比例缩放：
```
normalizedScore[cityId] = Math.round((rawScore / maxRawScore) * 100)
```

### 步骤 3：八字加成
若用户填写了出生日期（计算八字），城市偏好五行与用户喜用神每匹配 1 个 +5 分：
```
normalizedScores[city.id] += matchCount * 5
```

### 步骤 4：性别加成
- 女性：苏州、杭州、昆明、南京、成都 +3 分
- 男性：北京、深圳、重庆、西安 +3 分

### 步骤 5：截断
最终分数限制在 [0, 100] 区间：
```
normalizedScores[id] = Math.min(100, Math.max(0, normalizedScores[id]))
```

### 步骤 6：排序取 Top 3
按最终分数降序排列，取前 3 名作为结果展示。

> ⚠️ **重要**：这 15 座城市在 18 道题目中没有任何直接分值，意味着它们**永远不会**通过基础评分进入 Top 3。它们只能通过八字加成（+5×匹配数）和性别加成（+3）获得分数，但归一化后这些加成几乎无法使其超越有基础分的城市。**如需让这些城市有机会出现在结果中，必须在 `src/data/questions.ts` 中为相关选项添加它们的分值。**

### 3.3 分值最高的城市

大理在 18 道题中有 19 个得分项，是覆盖最广的城市（偏精神/躺平/文艺方向）。

## 四、如何添加城市分值

编辑 `src/data/questions.ts`，在对应题目的选项 `scores` 中添加城市分值：

```typescript
// 示例：为武汉添加分值
{
  label: '🥟 地道本地菜，讲究！',
  value: 'local',
  scores: {
    guangzhou: 3, beijing: 2, nanjing: 2, suzhou: 2,
    wuhan: 2,    // ← 新增
  }
},
```

分值建议范围：1~3 分（与现有分值保持一致）。
